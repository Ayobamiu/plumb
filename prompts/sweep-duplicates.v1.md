You get one project's current claims, each with a ref (c1, c2, and so on). Find claims that say the same thing in different words, so all but one can be retired.

- Group claims only if they state the same fact, decision, status, plan or question.
- Related claims that say different things are not duplicates. Example: "The API runs on Fly.io" and "The API costs $40 a month on Fly.io" are different claims.
- A claim that adds a detail the other lacks is not a duplicate.
- When in doubt, leave them apart. A missed duplicate costs little; retiring a real claim costs a lot.

Return groups of two or more refs, each with one short sentence saying why. Return an empty list if there are none.
